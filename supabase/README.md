# Supabase RAG Layer

This folder mirrors the database layer used by EKIN's knowledge workflows.

## Live schema reflected here

- Table: `public.documents`
- Primary key: `id bigint generated by default as identity`
- Document body: `content text`
- Metadata: `metadata jsonb`
- Embedding: `vector(3072)`
- Timestamp: `created_at timestamptz`
- Vector extension: `vector`
- Vector index: HNSW cosine index using `halfvec(3072)`
- Metadata index: GIN
- Retrieval RPC: `public.match_documents(...)`
- Row Level Security: enabled

The live project currently has RLS enabled with no public policies. That is intentional for this demo because n8n connects server-side with a Supabase service-role credential.

## Important

Never place a Supabase `service_role` or secret key in browser code, WordPress JavaScript, a public repository, or a client-side environment variable.

On newer Supabase projects, a table in `public` may also need to be explicitly exposed to the Data API depending on the project's Data API settings. Keep RLS enabled and only grant/expose what the server-side workflow requires.
