# Knowledge Base

Workflow 01 is designed to ingest company documents into Supabase.

For the EKIN demo, the RAG corpus was a **Nike Public Knowledge Base** built from publicly available official Nike sources and clearly marked as an unofficial educational portfolio resource.

The original DOCX corpus is intentionally not duplicated in this repository package because it was not part of the four workflow exports supplied for this submission. If you want the corpus versioned with the project, add it here as:

`Nike_Public_Knowledge_Base_RAG.docx`

Do not include customer data, private company records, access credentials, or copyrighted material you do not have permission to redistribute.
